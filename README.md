# ⚡ OmniCore AI — Intelligent Multi-Modal Assistant
**Created by Gaurav Tiwari (November 2026)**

OmniCore AI is a fast, full-stack conversational AI web application built with **Python (FastAPI)** and **Vanilla JavaScript**, featuring real-time web search, document/image vision analysis, voice interaction, and per-thread chat memory.

## 🚀 Key Features
- **Ultra-Fast AI Responses:** Powered by Groq LPU inference for sub-second answers.
- **Live Web Knowledge:** Automatic DuckDuckGo search integration for up-to-date facts and local information.
- **Document & Vision OCR (`+`):** Upload PDFs, code files, or images (including handwritten/printed math problems) for step-by-step solutions.
- **Voice Input & Read Aloud:** Built-in speech-to-text microphone (`🎙️`) and text-to-speech (`🔊`) support.
- **Per-Thread Chat Memory & Edit:** Isolated conversation history stored locally with message editing and regeneration.
- **HD Image Generation:** Natural language prompt-to-image synthesis.
